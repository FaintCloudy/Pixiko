# Pixiko Android 客户端

**v1.4.0 起新增**。作者：loriko（deloriko@outlook.com）。

把网页控制台**搬到手机上**的一个 Android app：包名 `cn.szu.bot.app`，版本 **1.4.0**。

---

## 一、这是什么

**原生外壳 + WebView 承载完整控制台。**

app 里显示的不是另写一套手机界面，而就是**你机器人发出来的那套网页控制台**。
所以：

- **网页有什么，app 里就有什么**——出图 / 提示词 / 样式 / LoRA / 提示词集 / 聊天配置 / 系统 /
  首次配置 / 日志 / 回执 / 帮助（**11 个栏目**）+ **常驻右侧的对话栏**，共 **13 栏**，
  按钮、表单、面板一个都不少；
- **以后网页更新，app 自动跟着更新**——不需要重新出包（app 每次都从你填的那台机器人加载页面）。

在此之上，原生外壳补了 **6 类网页做不到或做不好的能力**：

| 能力 | 说明 |
|---|---|
| **服务器管理** | 填地址 + 访问令牌即可连上；可保存**多台服务器**并一键切换 |
| **地址简写** | 填 `192.168.1.5:8787` 这种就行，app 会自动补 `http://` 与默认端口 **8787** |
| **测试连接** | 先打 `/healthz`，再打**带令牌的** `/api/status`，因此能**区分「连不上」和「令牌不对」** |
| **局域网扫描** | 按当前 Wi-Fi 网段扫 `:8787` 上的机器人，**找到就一键填入**地址 |
| **令牌自动注入** | 不用在网页的锁屏页里再敲一次令牌 |
| **图片保存 / 分享** | 在网页里**长按图片**即可**存进手机相册**（`Pictures/Pixiko`）或**分享出去** |
| **下拉刷新 / 进度条 / 原生错误页** | 连不上时不是一片白，而是列出可能原因并给「重试 / 去设置 / 用浏览器打开」 |

另外还有：**返回键行为**（回退 → 回首页 → 再按一次退出）、**屏幕常亮**开关、
**清网页缓存 / 清登录状态**、「在浏览器打开」、**关于**页；**文件选择、下载、新窗口、图片查看器**
都做了原生适配。

**手机宽度不用另做界面**：控制台本身就是**响应式的**（**≤1000px 变单列堆叠**），
**390×844 的手机宽度已在真机浏览器里验收过**（无横向滚动、右侧对话栏在下方堆叠、结构完整），
所以 app 里直接复用同一套网页。

## 二、三步用起来

1. **手机和电脑连同一个 Wi-Fi**（同一个局域网/网段）。
2. 打开 app，填两样东西：
   - **地址**：`电脑的局域网 IP:8787`（例如 `192.168.1.5:8787`；**只填 IP 也行**，端口默认就是 8787），
     或点「**扫描局域网**」自动找；
   - **访问令牌**：在**电脑**的 `config.json` 里，字段是 **`webui.access_token`**
     （首次启动若为空，机器人会自动生成一个并写回 `config.json`，日志里有）。
3. 点连接，进去就是**控制台**；**长按图片**可以存进手机相册 `Pictures/Pixiko`，或分享出去。

> 想确认地址和令牌都对，用 app 里的「**测试连接**」——它会分别报「连不上」还是「令牌不对」。

## 三、连不上怎么办？

真机上最常见的就是这一步。按下面顺序排查，基本都能解决。

**1. 地址和端口对不对**

- 电脑的局域网地址和机器人端口要对上。例如这台机器上是
  **`172.30.204.50`**（以太网，`/24`）、机器人监听 **`8787`**（`webui.host = 0.0.0.0`），
  那 app 里就填 **`172.30.204.50:8787`**（或点「扫描局域网」找）。

**2. 手机必须和电脑在同一个网段**

- 例如电脑是 `172.30.204.x`，手机也得在 `172.30.204.x`。
- **校园网 / 公共 Wi-Fi 常做客户端隔离**（同一 Wi-Fi 下设备之间互相看不见），
  这种网络里手机就是连不上电脑——用下面的第 4 条（USB）兜底。

**3. Windows 防火墙默认会挡住入站的 8787**

非管理员身份加规则会失败（`Access is denied`），所以**用管理员权限的 PowerShell 跑一次**
（只需一次）：

```powershell
New-NetFirewallRule -DisplayName 'Pixiko 控制台 (TCP 8787)' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 8787 -Profile Any
```

不想要了可以删掉：

```powershell
Remove-NetFirewallRule -DisplayName 'Pixiko 控制台 (TCP 8787)'
```

**4. USB 兜底（推荐给校园网 / 隔离网络）**

手机 USB 连上电脑、打开 **USB 调试**，然后在电脑上跑：

```powershell
adb reverse tcp:8787 tcp:8787
```

然后把 app 里的地址填成 **`127.0.0.1:8787`**——手机上的 `localhost:8787` 会被转发到电脑的机器人，
**完全不依赖 Wi-Fi 与防火墙**。

- `adb reverse` **每次重插 USB 后要重跑一次**；
- `adb` 在 **Android SDK 的 `platform-tools`** 里。

**5. 排查清单（照着走一遍）**

1. 地址 / 端口对不对？
2. 电脑自己的浏览器能不能打开 `http://127.0.0.1:8787`？
3. 手机浏览器能不能打开 `http://<电脑IP>:8787`？（**打不开就是防火墙或网段问题**）
4. 令牌对不对？（app 里「测试连接」会区分「连不上」与「令牌不对」）

## 四、怎么构建 APK

> 只是**想用 app**的话不需要看这一节：直接用构建好的 APK 装上就行（见下面「装到手机」）。
> 这一节讲的是**自己从源码构建**。

### 需要的工具链

| 组件 | 要求 |
|---|---|
| **JDK** | **JDK 21**（脚本用 `-JdkHome` 指定，比如 Android Studio 自带的 JBR） |
| **Android SDK** | `platform-tools`、`platforms;android-34`、`build-tools;34.0.0` |
| **Gradle** | **8.9 – 8.14**（与 AGP 8.x / `compileSdk 34` 匹配） |

工程本身的参数：Java、Android Gradle Plugin **8.x**（根 `build.gradle` 里是 **8.6.1**）、
`compileSdk 34`、`minSdk 26`、`applicationId` **`cn.szu.bot.app`**、版本 **1.4.0**。

### 一键构建

仓库里带了一个脚本 `android/build-apk.ps1`，它会用你指定的 JDK 与 Android SDK 跑
`assembleDebug`，并把 APK **复制到输出目录** `F:\Bot\android\dist\`：

```powershell
powershell -File android\build-apk.ps1 -SdkRoot <Android SDK 路径> -JdkHome <JDK 21 路径>
```

- `-SdkRoot`：Android SDK 根目录（里面应有 `platform-tools\`、`platforms\android-34\`、
  `build-tools\34.0.0\`）；
- `-JdkHome`：**JDK 21** 的根目录；
- 在**仓库根目录**执行（或者把 `android\build-apk.ps1` 换成实际路径）。

### 产物在哪

Gradle 的原始产物：

```
android\app\build\outputs\apk\debug\app-debug.apk
```

脚本会把它复制到输出目录 **`F:\Bot\android\dist\`**。

### 装到手机

两种方式，任选一种：

1. **USB（`adb install`）**：

   ```powershell
   adb install -r android\app\build\outputs\apk\debug\app-debug.apk
   ```

2. **直接拷进手机**：把 APK 复制到手机里（数据线 / 聊天工具传文件都行），在手机上点它安装。

> 这是 **debug 包，由 debug 密钥签名**，不是正式发布签名。Android 会要求你允许
> 「**安装未知来源应用**」（各机型路径不同，一般在「设置 → 应用 → 特殊权限」里）。

## 五、安全与隐私

- **局域网 http 明文传输**：app 连机器人走的是 `http://`（`usesCleartextTraffic`），
  **同网段的人有办法看到内容**——所以**只建议在家里或可信局域网用**。
- **令牌是明文存的**：访问令牌保存在 **app 私有目录**的 `SharedPreferences` 里，**没有加密**。
  手机被 root、或装了能读私有目录的工具，令牌就可能被读出来。
- **app 不向任何第三方服务器发数据**：它只连**你自己填的那台机器人**。
- 想少一分风险：**别把 8787 直接暴露到公网**，用完可以在路由器/防火墙上关掉。

---

## 六、已知限制

1. **没有后台推送**：机器人来了新的**回执**，app 不会弹通知，得**自己打开 app 看**。
2. **不做手机端专属界面**：用的是**响应式网页**本身，没有为手机重画一套面板。
3. **平板 / 横屏能跑，但没专门打磨**：能用，只是排版没针对大屏横屏优化过。
4. **「在浏览器打开」是排查用的**：网页端的这个入口主要是**对比排查**——
   同一地址在手机浏览器里能不能开，能开就说明网络通、问题在 app 侧。
