## 第一部分 · WebUI 侧（0:30–3:30）

### A1｜Agent 改词：大白话进去，提示词出来（0:30–1:35）★ 核心

**画面**：`.infix 把背景换成黄昏的屋顶` → 提示词被改写并应用（**左右对照显示改前改后全文**）→ `.infix filter on` 前后对照（瞎造词 vs 真实词条）→ `.progen 一张雨夜车站的少女` 只出建议 → 一句描述被拆成「人物 / 场景 / 光线 / 镜头」四类 → 用改写后的词出图，接开场那张对比图。

**口播**：
> 先说最重要的一块，也是我做这个机器人的原因。
> 原版 SD 的门槛不是软件难装，是**你不知道该写什么词**：Danbooru 那套词库是英文的、十几万条，什么词放前面、哪些词配在一起好看、权重给多少——不熟的人打了半天，出来还是不好看。
> 所以它的核心能力是：**你用大白话，它替你写成提示词**。`.infix 把背景换成黄昏的屋顶`，模型直接改你当前的提示词并应用，不用你查任何英文词。
> 怕它乱编？打开 `.infix filter on`，改动会被约束在**标准词库里真实存在的词条**上——不会给你造一个 WebUI 根本不认识的词。这是自己写 prompt 喂给模型改写时最容易踩的坑。
> 只想找灵感就用 `.progen`：给一句描述，它只出建议，不动你已经写好的词。
> 它还能把一句话拆开：你说「雨夜车站的少女」，它给你拆成人物、场景、光线、镜头这几类——**新手最缺的就是这个结构感**，很多人出图不好看，就是因为只写了人物。

**花字**：**不会写词？就用大白话**　`.infix` 直接改并生效　**词库约束 · 不瞎造词**　`.progen` 只给建议　**一句话拆成四类**

> 为什么是"打字"而不是图形界面：模型点不了鼠标，**文本指令就是它唯一能用的手**。这句在 A1 里讲一次即可，不要单独做"指令替代点击"的演示。

### A2｜词库：你不用背它（1:35–2:15）

**画面**：控制台输入框敲 `he` 按 Tab 补全成标准词条（近景）→ 空输入框按 `Ctrl+Space` 弹出最热词列表 → `.usage 搜索 和服` → `.usage 词条` 显示词意与使用场合 → `.prompt classify` 分类列表（高亮"缺了光线和镜头"）。

**口播**：
> 第二块，词库——**你不用背它**。14 万条标准词条、3 万 4 千条中文对应、3 万 8 千个中文写法，**随包自带，不用装任何扩展**。
> 网页控制台里敲几个字母、或者直接打中文，按 Tab 就补成标准词条，↑↓ 选；空输入框上按 Ctrl+Space 直接列最热词——不知道写什么，就从最热的下手。
> 群里可以 `.usage 搜索 和服` 直接搜；`.usage 词条` 不只看翻译，还会告诉你**这个词什么场合该用**；`.prompt classify` 把当前提示词按类别摆开，你会一眼看出自己少了哪类词——很多人出图不好看，就是只写了人物、没写光线和镜头。`.prompt keep`、`.prompt drop` 再按类删改，`.prompt undo` 二十步回退。

**花字**：**14 万条中文词库 · 随包自带**　`Tab 补全`　`Ctrl+Space 最热词`　`.usage 词条` 教你怎么用　`.prompt classify` 看结构

### A3｜LoRA：不懂也能用上（2:15–2:55）

**画面**：`.char 角色名` 列出本机 LoRA 与样式候选 → `.lora query 关键词` 出带封面的列表 → `.lora download #3 0.8` 下载、启用 → **展示图提示词自动存成样式** → `.style load` 复现同款效果 → `.style import webui` 搬家。

**口播**：
> 第三块，LoRA。这块门槛更高——模型那么多，哪个配哪种画风、从哪儿下、权重给多少，新手基本靠碰运气。
> `.char 角色名` 先在你本机的 LoRA 和 WebUI 样式里找候选，不用一个个翻文件夹。想找新的，`.lora query 关键词` 直接搜 Civitai，列表带编号和封面，看图选就行。
> 最有用的是一句 `.lora download #3 0.8`：它把 LoRA 下载下来、装上、按你给的权重启用，**顺手把作者展示图的提示词存成样式**——你想要刚才那张展示图的效果，`.style load` 一句话就能复现，不用自己猜人家怎么写的。
> 你在 WebUI 里存好的样式也能一次搬过来：`.style import webui`。

**花字**：`.char` 找角色　**看图选 LoRA**　`.lora download` 下装启用 **+ 抄回提示词**　`.style load` 复现同款

### A4｜参数与队列（2:55–3:30）

**画面**：`.settings` → `.preset save` → `.function save` → `.gen 4` → `.gen list` → `.gen first` / `.gen hold` → `.progress` → `.sd auto on` → 成图发回群 / `.get`。

**口播**：
> 剩下的是省事的部分，不用给太多时间。参数不用自己摸：`.settings` 看当前尺寸、采样方法、步数、CFG、种子和基础模型；`.preset` 存参数组合，`.function` 存整套提示词集——调好一次，以后一句话换回来。
> 出图比 WebUI 多一个真队列：`.gen 4` 一次排四个任务，`.gen list` 看进度和是谁的任务，`.gen first` 置顶、`.gen hold` 挂起、`.gen cancel` 取消，`.progress` 一屏同时看 WebUI 进度和队列。
> SD 也能让它自己拉起来：`.sd auto on` 之后开机不用先开 WebUI。出完的图机器人发回原对话，`.get` 分批领、`.rg` 回溯最近的图。

**花字**：`.settings` / `.preset` / `.function`　**真队列**：置顶 · 挂起 · 取消　`.sd auto on`　`.get` / `.rg`

## 第二部分 · QQ 端（3:30–4:35）

### B1｜让群友也能用上你这台机器（3:30–3:55）

**画面**：@机器人（或叫她的名字）→ 群友直接用 `.infix` 和 `.gen` → 私聊 → `.admin list` → `.batch` 一次跑多条。

**口播**：
> QQ 这一端解决的是另一件事：**让别人也能用上你这台机器**。群友不用装任何东西、不用有你这台电脑的权限，界面就是群聊——对他们来说，出图门槛就只剩"会打字"。
> 群里 **@ 她或者叫她的名字才会回**；回完之后要不要把你留在三十分钟的对话窗口里，**由她按这次对话判断**——留在窗口里，接下来不 @ 也能继续聊，没留在窗口里就只回那一句。私聊不用唤名，每条都回；`.` 开头的消息只走指令，不进入日常聊天。
> 权限是分层的：owner、admin、群白名单、用户白名单，owner 专属指令别人碰不了。`.batch` 能用一条消息顺序跑最多二十条指令。

**花字**：**群友不用装任何东西**　**门槛只剩"会打字"**　`@ 或叫名字才回 · 窗口由她定`　`owner / admin / 白名单`

### B2｜人格、群互动与地图（3:55–4:15）

**画面**：`.chat personality` → `.chat frequency` → `.affinity` → `.jrlp` → `.结婚` / `.同意` → `.yh` 地图发出。

**口播**：
> 她还有人格，可以自己改：`.chat personality` 写设定、`.chat add` 追加、`.chat infix` 让模型自己改。`.chat frequency` 限流，设成 0 就等于这个会话完全不回；她**只回应 @／提及**，被点名之后要不要继续聊由她判断，所以不会满屏刷话；`.affinity` 记好感度。原作语料复现是可选项，语料要自备，文件不在就静默降级。
> 群互动也有：`.jrlp`、`.结婚`、`.同意`、`.拒绝`、`.强娶`、`.离婚`，还有 `.yh`、`.liv` 两张校园地图——粤海和丽湖**已经随包**，装上就能发。

**花字**：`.chat personality` / `.affinity`　**只回应 @／提及，之后由她判断**　`.jrlp` / `.结婚`　`.yh` / `.liv`

### B3｜控制台、禁言与收尾（4:15–4:35）

**画面**：控制台十栏目快扫 → 上下线播报进主群 → 日志里一条「禁言中，跳过发送」→ 尾板 + 下 P 预告卡。

**口播**：
> 管理都在网页控制台里，十个栏目：对话、聊天配置、提示词、样式、出图、LoRA、提示词集、日志、系统、配置，改配置看日志管队列都在这儿，手机也能开。
> 被禁言时她不硬发，只记一条「禁言中，跳过发送」，不刷一屏报错，解除后自己恢复，这期间聊天也不调模型，不烧额度。而且不接 QQ 也不耽误事——网页控制台和出图照常能用。
> 这一 P 就到这。下一 P 手把手把四个依赖配完：SD WebUI、NapCat、DeepSeek、Civitai。

**花字**：**10 个栏目 · 手机也能开**　**禁言自动退让**　**下一 P：部署流程教程**

## 第 1 步 · SD WebUI（0:30–1:10）

**画面**：`webui-user.bat` 里加 `--api` → 启动出 `Running on local URL: http://127.0.0.1:7860` → 控制台填 `sd.base_url` → 保存 → 终端 `run.bat --check` 输出连通。

**口播**：
> 第一步，SD WebUI——就是你平时出图那个，不用换。只有一个要求：**启动参数里必须带 `--api`**，少了它机器人连不上，这是最容易踩的坑。默认地址 `http://127.0.0.1:7860`，填进配置的 `sd.base_url`。
> 想让她帮你把 SD 拉起来，就填 `sd.root`——WebUI 的根目录，她会自己去找 `python` 加 `launch.py`，或者 `webui-user.bat`。然后 `auto_start` 管「生成前自动拉起」，`start_on_boot` 管「随机器人启动」，默认分别是开和关。启动参数在 `start_args` 里配，**同样必须含 `--api`**。如果你的 WebUI 开了 `--gradio-auth`，把账号密码填进 `api_username`、`api_password`。
> 配完先验一下：`run.bat --check` 只测 SD 连通性，不启动机器人。没有 WebUI 也能先跑，只是出不了图。

**花字**：**必须带 `--api`**　`sd.base_url`　`sd.root` 自启动　`run.bat --check`

## 第 2 步 · NapCat（1:10–1:40）

**画面**：NapCat 里打开「正向 WebSocket 服务器」→ 看到端口 3001 与 Token → 填进控制台 `qq.ws_url` / `access_token` → 保存 → 重启机器人 → 群里出现上下线播报。

**口播**：
> 第二步，NapCat，这是 QQ 那条腿。在 NapCat 里开**正向 WebSocket 服务器**，默认 `ws://127.0.0.1:3001`，把地址和 Token 填进配置的 `qq.ws_url` 和 `access_token`，另外两个是超时和重连间隔。
> 注意顺序：**先起 NapCat，再起机器人**。还有一点，NapCat 其实是可选的——不接 QQ，网页控制台和出图照样能用，只想自己用的话可以跳过这一步。地址这类东西改完要重启机器人才生效。

**花字**：**正向 WebSocket**　`ws://127.0.0.1:3001`　**可选，不接也能用**　**地址改动要重启**

## 第 3 步 · DeepSeek API（1:40–2:10）

**画面**：控制台「系统 → DeepSeek 通道」两条通道并排 → 填 `api_base`（留空即官方）→ 粘密钥 → 点「测试连接」→ 页面回显掩码 `sk-6…222` → 改完不重启，直接 `.infix` 生效。

**口播**：
> 第三步，DeepSeek，**这一步才是刚才那些"替你写词"的能力来源**，不能省。这里有两条**独立通道**：生图频道管改写，聊天频道管陪聊，地址、密钥、模型、额度都是分开的，改一条不影响另一条。地址留空就用官方 `api.deepseek.com`。
> 密钥不是写进 `config.json` 的，而是落到 `data/deepseek-api-key.txt` 和 `data/deepseek-chat-api-key.txt` 这两个文件里；页面只回显掩码，任何响应里都不会出现原文，这两个文件也不进版本库。填完点「测试连接」，通了就完事。
> 两件事记住就好：**DeepSeek 的地址和密钥改完立刻生效，不用重启**；没有 Key 也能启动，只是改写和日常聊天不可用，出图不受影响。

**花字**：**改写能力的来源**　**两条独立通道**　`progen` / `chat_api`　**密钥只写本机 · 只回显掩码**　**改完即时生效**

## 第 4 步 · Civitai（2:10–2:40）

**画面**：控制台点「Civitai 登录」→ 复制邮件里的一次性登录链接整条粘贴 → 保存成功 → 群里 `.lora query` 出结果、带封面 → `.lora download #3 0.8` 下载并启用 → 展示图提示词自动存成样式。

**口播**：
> 第四步，Civitai，这是 LoRA 的来源，也是"不懂 LoRA 也能用"的来源。先在配置里填 `civitai.lora_dir`——**不填就用不了 Civitai 下载和 LoRA 列表**，其余功能不受影响。
